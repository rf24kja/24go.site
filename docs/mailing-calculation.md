## Рекомендации

1. **Начинать с 10-15 аккаунтов** — набрать опыт
2. **Не превышать 50 сообщений/аккаунт/день** — даже для зрелых
3. **Использовать рандомную задержку** — 45-120 секунд (±30%)
4. **Мониторить flood-wait** — если 3+ аккаунта в flood-wait → пауза
5. **Чередовать тексты** — 3-5 вариантов сообщения (A/B тест)
6. **Персонализация** — {first_name} повышает конверсию на 30-50%
7. **Не писать в нерабочие часы** — 22:00-08:00 по времени получателя
